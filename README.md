# Игра «Взломщик кода»

Небольшая консольная игра на Python для практики автоматического тестирования.
Игроку даётся **10 ходов**, чтобы угадать код из четырёх разных цифр.

После попытки игра показывает:

- **быки** — правильные цифры на правильных местах;
- **коровы** — правильные цифры на неправильных местах.

## Запуск игры

Откройте терминал в папке проекта и выполните:

```bash
python codebreaker.py
```

## Запуск тестов

```bash
python -m pip install -r requirements.txt
pytest -v
```

В тестах проверяются корректный и ошибочный ввод, подсчёт быков и коров,
генерация секрета, победа на 10-м ходу, поражение после 10 ходов и то, что
ошибка ввода не отнимает ход.
